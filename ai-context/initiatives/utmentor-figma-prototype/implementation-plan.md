# Implementation plan: UTMentor en Figma

## 1. Archivo y foundations

- Crear el archivo `UTMentor · Web App & Prototype`.
- Crear páginas para foundations, componentes, sitio público, autenticación, panel de asesor, panel de asesorado y flujos.
- Definir variables de color, espaciado y radio, además de estilos tipográficos Inter.

## 2. Componentes

- Logo y navegación pública.
- Botones primarios, secundarios, ghost, peligro e icono.
- Inputs, selects, campos de búsqueda y controles de contraseña.
- Tarjetas de asesor, sesión, beneficios, métricas, temas y calificaciones.
- Sidebar, topbar, filtros, paginación, calendario, modal, toast y estados vacíos.

## 3. Pantallas

- Público: inicio, explorar, perfil público, políticas y donación.
- Autenticación: acceso, recuperación, registro, selección de rol y restablecimiento.
- Asesor: sesiones, publicación y perfil/temas.
- Asesorado: sesiones, explorar, calificar, favoritos y perfil.
- Adaptaciones móviles principales.

## 4. Imágenes

- Capturar la aplicación únicamente como referencia de precisión.
- Transferir fotografías, avatares y logotipos como assets independientes.
- Eliminar cualquier captura completa usada como referencia antes de entregar.

## 5. Prototipo

- Conectar navegación pública y autenticación.
- Simular filtros, selección de asesor, horarios, reserva, favoritos y calificación.
- Simular navegación lateral, cambio de rol, modales y confirmaciones.

## 6. Validación

- Verificar que las pantallas estén compuestas por capas editables y componentes.
- Comprobar variables, estilos, uso de Inter, imágenes y ausencia de capturas completas.
- Revisar visualmente los frames principales y corregir recortes, solapamientos o placeholders.

## 7. Entrega

- Entregar enlace al archivo Figma.
- Publicar esta iniciativa mediante PR hacia `Dev`.
